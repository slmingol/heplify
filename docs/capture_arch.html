Why higher ceiling:
PACKET_FANOUT = kernel distributes before userspace ever sees packets
Go goroutine scheduler: N workers auto-spill across cores
20k-deep channel = burst absorption without kernel drops
Prometheus metrics → observe drops before they become incidents
~15–30 MiB RSS vs 84–100 MiB (lower working set per packet/s)
Immediate levers (captagent, no code change)
📦
ring_buffer 12 → 64 MiB
Edit socket_pcap.xml: <param name="ring-buffer" value="64"/>

Buys burst headroom. Costs ~52 MiB RSS per interface. Doesn't raise the throughput ceiling — just delays when you hit it.
🧵
threads 4 → 8
Edit socket_pcap.xml: <param name="threads" value="8"/>

Marginal gain — libpcap still serializes ring access. Diminishing return past ~6. Worth testing under load.
